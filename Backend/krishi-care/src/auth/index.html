General Information

This document provides a concise overview of the key API endpoints for the KrishiCare application. It is designed to help frontend developers understand and interact with the backend services.

Base URL

The base URL for all API calls during local development is:

http://localhost:3000

Authentication

Protected endpoints require a JSON Web Token (JWT) to be sent in the `Authorization` header. You can obtain this token from the User Login endpoint.

Authorization: Bearer <YOUR_ACCESS_TOKEN>

File Uploads

Endpoints that accept files, like User Registration, must use the `multipart/form-data` content type.

POST

/users

Creates a new user account (Farmer or Specialist) with an associated profile and handles optional image uploads.

Parameters (`multipart/form-data`)

Each parameter is a separate field in the form data. Use the dropdown below to see conditional fields.

Key Type Required Description
username String Yes Unique username for login.
password String Yes User's password.
fullName String Yes Full name of the user.
phoneNumber String Yes Unique phone number.
roleName String Yes Defines user type. Must be `"FARMER"` or `"SPECIALIST"`.
profilePicture File No Optional image file (JPG, PNG, GIF) for any role.
farmName String Conditional Required if `roleName` is `"FARMER"`.
specialization String Conditional Required if `roleName` is `"SPECIALIST"`.
certificationImage File Conditional Image file (JPG, PNG, GIF). Required if `roleName` is `"SPECIALIST"`.

Expected Output (201 Created)

{ "id": "user-uuid-xyz", "username": "jane.doe", "fullName": "Jane Doe", "phoneNumber": "9123456789", "profilePictureUrl": "/uploads/unique-profile-pic.jpg", "roleId": "role-uuid-farmer", "createdAt": "2025-06-15T...", "updatedAt": "2025-06-15T...", "role": { "id": "role-uuid-farmer", "name": "FARMER" }, "farmerProfile": { "id": "profile-uuid-abc", "farmName": "Green Harvest Farm", "userId": "user-uuid-xyz" } }
POST

/auth/login

Authenticates a user and returns a JWT `access_token` along with detailed user information.

Parameters (JSON Body)

{ "username": "your_username", "password": "your_password" }

Expected Output (200 OK)

{ "access_token": "YOUR_GENERATED_JWT_TOKEN_HERE", "user": { "id": "user-uuid-xyz", "username": "jane.doe", "fullName": "Jane Doe", "phoneNumber": "9123456789", "role": "FARMER", "profilePictureUrl": "/uploads/unique-profile-pic.jpg", "farmName": "Green Harvest Farm" // For SPECIALIST, farmName would be replaced by: // "specialization": "Crop Nutrition", // "certificationImage": "/uploads/unique-cert-image.png" } }
GET

/uploads/:filename

Retrieves a previously uploaded image file by its unique filename.

Parameters (URL Path)

The `filename` is provided in the `profilePictureUrl` or `certificationImage` fields from other API responses.

Example URL:

http://localhost:3000/uploads/unique-profile-pic.jpg

Expected Output (200 OK)

The raw image file content, which a browser or frontend client can render as an image.
